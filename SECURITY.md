# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a Vulnerability

Please report security issues privately to **security@trykintsugi.com**.

Include:

- A description of the issue and potential impact
- Steps to reproduce
- Affected plugin version and Kill Bill version

We aim to acknowledge reports within two business days.

Please do not open public GitHub issues for security vulnerabilities.
